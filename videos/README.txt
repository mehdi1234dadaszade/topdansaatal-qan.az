Put your home page background video here and name it store.mp4  (it plays muted, looping, full screen behind the home page).
Tip: use a short (10-30 s) H.264 mp4, 1080p or lower, under about 15 MB so it loads fast. GitHub limit per file: 100 MB.
You can use another file name or a link in Admin > Design. Optional: a YouTube link as the background can also be set there.
